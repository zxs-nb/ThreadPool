\# C++ ThreadPool



基于 C++11/14/17 实现的线程池项目，

用于学习现代 C++ 并发编程。



\## 项目介绍



实现一个支持任务提交、异步获取任务返回值

以及线程安全任务调度的线程池。



\## 核心功能



\- \[x] Any 类型封装

\- \[x] Result 类封装

\- \[ ] 泛型任务提交

\- \[ ] std::future 获取任务返回值

\- \[ ] 线程池动态扩容

\- \[ ] 线程池优雅关闭



\## 技术栈



\- C++

\- STL

\- std::thread

\- std::mutex

\- std::condition\_variable

\- std::future
